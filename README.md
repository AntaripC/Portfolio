# Antarip Chatterjee — Cloud Computing Engineer & Portfolio

> **“Building under pressure. Leading teams. Turning ideas into working solutions.”**

A developer portfolio with a dark, futuristic cybernetic design featuring an interactive 3D cloud infrastructure model, live telemetry HUDs, command-line terminal interface, and interactive project showcases.

---

## 🚀 Tech Stack

- **Core & Framework**: React 18, Vite
- **3D & Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animations & Interactivity**: Framer Motion, Lenis Smooth Scroll
- **Icons & Styling**: Lucide React, Vanilla CSS (Glassmorphism, custom cyber theme)
- **Particles**: `@tsparticles/react`, `@tsparticles/slim`

---

## 🛠️ Local Development

### Prerequisites
- Node.js (v18 or higher recommended)
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/AntaripC/Portfolio.git

# Navigate into the project folder
cd Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will run locally at `http://localhost:5173/`.

### Production Build

```bash
npm run build
```
